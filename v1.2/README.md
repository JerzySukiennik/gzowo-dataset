# Gzowo Dataset

Everything known about Gzowo 34, a family plot on the Narew river in Poland: place, history, people, animals, gear, rituals, sayings, memories, brands (Gzowo Labs, GSP) and media. Built mainly as source material for a game about Gzowo. Content is in Polish.

- Site: https://dataset.gzowo.fun/
- For AI agents: start with `llms.txt`, the full text is `gzowo-dataset.md`, structured data is in `data/`, every photo and video is described in `data/media.json`.
- Rebuild: `python3 Niepotrzebne/tools/build.py` (sources in `Niepotrzebne/src/`).
